# Gestão de Contratos de TI — API

> 🚧 **Em desenvolvimento.** O código está sendo construído em etapas; acompanhe pelos commits.

API REST para acompanhamento de contratos de fornecedores de TI, com controle de vigência, alertas de vencimento e histórico de aditivos.

## Stack
Java · Spring Boot · JPA/Hibernate · SQL Server · Swagger/OpenAPI · JUnit · Mockito · Docker

## Como rodar
Instruções com Docker serão adicionadas quando a primeira versão da API estiver pronta.
